# 孤独症儿童表情识别常模

## 项目简介

本项目旨在构建一个面向孤独症儿童表情识别能力评估与分析的软件系统，重点覆盖两类核心任务：

1. 图像表情分类/识别任务
2. 视频表情判别任务

系统通过对不同情绪表达样本进行识别和判断，评估受试者在“识别表情情绪”方面的能力，并结合视频表情识别模型的输出生成综合报告。该项目适用于研究场景、临床辅助评估和表情认知能力分析。

---

## 业务目标

该软件主要实现以下功能：

- 对图像中的情绪进行分类或识别
- 对给定的两张图像或多张图像进行情绪判断，回答“哪一张图像更符合开心/其他情绪”
- 对视频中人物面部表情进行实时或离线判别
- 将视频表情识别模型的结果与目标结果进行对比
- 综合各部分得分，生成最终评估报告

---

## 核心功能

### 1. 图像分类/识别功能

该功能用于对图像进行情绪分析，主要包括两种任务形式：

#### 1.1 二选一图像分类

给出两张图像，用户提问：

- “下面哪张图片是开心的？”
- “哪张图像更能体现快乐情绪？”

系统需要根据图像内容判断：

- 识别图像中人物的表情特征
- 识别情绪状态（如开心、愤怒、生气、悲伤、惊讶等）
- 输出最符合该情绪的图像选项

#### 1.2 多选图像识别

给出多张图像，用户提问：

- “下面哪一张图像是开心的？”
- “在这些图片中，哪一张表达了快乐？”

系统需要从多张候选图像中识别出最符合目标情绪的图像，并给出判断依据。

#### 1.3 设计目标

这部分功能重点考察：

- 图像表情识别能力
- 情绪分类准确性
- 对不同表情样本的敏感度

---

### 2. 视频表情判别功能

该部分用于处理视频输入，系统会给出一段视频，其中没有提供选项，要求调用视频表情识别模型根据屏幕前人物的面部表情自动判断其情绪状态。

#### 2.1 任务形式

输入：

- 一段视频
- 没有预设选项或标准答案

处理流程：

- 使用视频表情识别模型对人脸进行逐帧分析
- 提取面部动作特征、表情变化、情绪状态
- 判断当前人物的主要情绪（如开心、悲伤、愤怒、惊讶等）
- 输出表情识别结果
- 同时给出解释说明，例如：
  - 眨眼、嘴角上扬、眉部舒展等特征表明开心
  - 表情变化持续时间、面部动作幅度、关键动作模式支持该判断

#### 2.2 模型输出要求

视频表情识别模型不仅仅返回最终标签，还应提供：

- 表情类别结果
- 置信度或判别强度
- 关键面部特征分析
- 解释性说明（如“嘴角上扬、眼睛舒展，符合开心表达”）
- 可能的情绪变化过程描述

这样可以提升算法的可解释性，并便于与目标结果进行比较分析。

---

## 结果对比与评分机制

系统的最终目标不仅是识别表情本身，还需要将各部分结果进行汇总和对比，形成综合评估。

### 3.1 图像任务评分

对图像分类/识别任务，系统需要记录：

- 用户或模型是否正确选择了目标图像
- 正确率
- 在二选一和多选情境下的表现差异
- 对不同情绪类别的识别准确率

### 3.2 视频任务评分

视频任务中，系统需将模型输出与实际目标结果进行比对：

- 视频表情识别模型判断是否与真实/参考结果一致
- 结果是否准确
- 解释是否合理、是否与面部特征一致
- 模型对于情绪变化判别的稳定性

### 3.3 综合评分报告

最终系统根据以下信息生成报告：

- 图像二选一得分
- 图像多选识别得分
- 视频表情识别结果得分
- 解释质量评分
- 总体表现评分

最终输出为一份完整的评估报告，并给出结论，例如：

- “总体表情识别能力良好”
- “图像识别正确率较高，但视频情绪判别解释性有待提升”
- “对开心表情识别表现优于其他情绪类别”

## 预期输出

系统最终应能够输出以下内容：

1. 图像分类/识别结果
2. 视频表情识别结果
3. 识别解释说明
4. 与目标结果对比分析
5. 总体评分
6. 评估报告

示例输出结构：

```text
任务一：图像二选一识别
- 选项A：正确
- 选项B：错误
- 结果：A 为开心表情

任务二：图像多选识别
- 识别结果：第3张图像为开心
- 正确率：80%

任务三：视频表情判别
- 识别结果：开心
- 置信度：0.87
- 解释：嘴角上扬，眉毛轻度上扬，面部表情符合开心状态

综合报告：
- 图像任务得分：85/100
- 视频任务得分：82/100
- 总体评分：83.5/100
- 结论：整体情绪识别能力较好，视频解释性分析可进一步优化
```

## 技术思路

该项目的核心技术路线可概括为：

- 图像特征提取：人脸检测、表情特征编码、情绪分类
- 视频分析：帧级表情提取、时序建模、情绪变化识别
- 结果比对：将模型输出与参考答案或标准标签对齐
- 解释生成：结合面部动作单元和情绪特征给出文字说明
- 评估报告：汇总各部分能力指标并输出最终结论

## 注意事项

本项目用户主要是儿童，因此软件界面应采用色彩丰富、饱和度较高、视觉冲击感强的设计风格，以提升小朋友的注意力、参与兴趣和操作体验。界面应尽量避免过于单调、低饱和或低对比度的配色，建议使用明亮的暖色系、清晰的色块分区和高辨识度的图标与按钮，帮助儿童更容易理解界面内容和任务目标。

同时，界面设计需要兼顾儿童友好性与可用性：

- 使用鲜明且易识别的色彩组合，提升视觉吸引力
- 保持较高的饱和度和适度对比度，避免过度沉闷
- 采用直观、简洁的布局，减少复杂信息干扰
- 提供大尺寸按键和清晰提示，方便儿童操作
- 适当加入卡通化、趣味化元素，增强学习和互动体验

总体而言，本软件的界面应设计为“色彩丰富、充满活力、适合儿童认知特点”的儿童友好型界面，以提高儿童参与度和评估体验。

## 结论

本项目的核心价值在于将“图像情绪分类/识别”和“视频表情判别”两类能力结合起来，并通过统一的评分与报告机制，形成针对表情理解能力的系统化评估方案。该方案不仅关注最终结果的正确性，也强调解释性和综合分析，从而更适合用于 ASD 相关表情识别能力研究与评估。
