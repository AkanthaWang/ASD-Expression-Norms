# ASD 儿童情绪识别评估：前置调研问卷

**版本**：V1.0（研究准备阶段）  
**对象**：儿童家长、主要照护者或熟悉儿童日常表现的教师  
**预计时长**：8-12 分钟  
**用途**：了解受试者背景、日常情绪理解表现、图片/动画材料偏好和评估体验，为题库与界面迭代提供依据。

> **使用边界**：本问卷是调研工具，不是 ASD 筛查量表，不作诊断，也不替代专业评估。问卷答案不直接并入现有 30 分任务分数。涉及诊断、发育或健康的信息只用于研究分层和解释，需获得知情同意并进行脱敏存储。

## 一、调研目标

1. 确认不同年龄、语言水平和既往经历的儿童是否能理解“开心、悲伤、害怕、生气”等题目用语。
2. 了解儿童在真实生活中识别他人情绪的场景、困难和可用线索。
3. 比较照片、卡通插画、动画表情和情境图片的接受度，筛选适合正式题库的刺激材料。
4. 识别屏幕、陌生环境、摄像头、声音和任务时长带来的负担。
5. 收集家长/教师对反馈报告、隐私说明和操作流程的需求。
6. 为后续可用性测试、题目难度平衡和正式常模研究建立分层变量。

建议采用 6 页、每页 3-6 题的单列布局；顶部显示进度，底部固定“上一页 / 下一页”，不使用长表格。

### 交互规范

- 每页只保留一个主要任务，单选题点击整行即可选中；选中态使用高对比边框和勾选图标。
- 必答题在题干旁显示“必答”，不使用红色大段错误提示；漏答时在题目下方提示“请先完成此题”。
- 多选题标注“最多选 3 项”，超过上限时即时阻止，而不是提交后报错。
- “其他”选项展开一个短文本框；“不清楚/不适用”始终保留，避免强迫猜答。
- 对诊断、病史和隐私问题使用折叠说明和明确的“可跳过”标记。
- 移动端每个选项最小点击高度 48px；支持键盘 Tab、方向键和屏幕阅读器标签。

## 五、调研分析计划

1. **描述统计**：按年龄段、沟通方式和受访者身份统计材料偏好、可接受时长和常见困难。
2. **交叉比较**：比较照片、绘本插画、卡通脸和动画片段在不同年龄/沟通方式下的接受度。
3. **题目筛选**：将“理解度低、负担高、家长认为容易误导”的题目列为修改候选，不依据单一回答直接删除。
4. **流程优化**：重点观察练习题、暂停、成人读题、AAC/指认和进度提示的需求比例。
5. **开放题编码**：由两名研究人员独立归类 Q15、Q16、Q28，记录一致率和分歧原因。
6. **正式研究前复核**：问卷结果只能指导材料和交互设计；正式量表仍需独立样本的信度、效度、项目难度和年龄常模验证。

## 六、实施注意事项

- 不把家长对孩子的主观评价直接转换成 ASD 风险等级。
- 不要求儿童必须看眼睛、模仿笑脸或用口语说出情绪词。
- 敏感问题提供“不清楚/不适用/不愿回答”，避免迫使受访者猜测。
- 联系方式与研究答案分开保存，视频/摄像头相关问题单独说明保存期限和删除方式。
- 进行正式调研前，先找 3-5 位家长完成认知访谈，检查题目是否易懂、选项是否遗漏、页面是否造成压力。
