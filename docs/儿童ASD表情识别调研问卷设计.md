# 儿童 ASD 表情识别调研问卷设计

**版本**：V1.0（项目调研与原型验证版）  
**适用对象**：2.5-6 岁儿童；家长/主要照护者；幼儿园教师或康复训练人员  
**使用场景**：验证图片与视频任务的可理解性、可接受性、完成度和初步区分度  
**重要边界**：本问卷和项目任务不是医学诊断工具。问卷结果不能直接判断或排除 ASD，正式应用前仍需完成伦理审批、知情同意、题目效度、信度和年龄常模验证。

## 一、调研目标

1. 了解儿童是否能在低语言负担条件下区分开心、悲伤、恐惧等基本表情。
2. 比较静态图片任务与动态视频任务在正确率、反应时间、疲劳和拒答上的差异。
3. 检查动画表情素材是否适合儿童：是否易懂、刺激强度是否合适、是否引起害怕或过度兴奋。
4. 记录语言理解、情绪词汇、视听条件、注意力和施测状态等影响因素。
5. 为后续题库优化、平行题开发和正式常模研究收集反馈。

## 二、推荐问卷结构

| 模块 | 填写人 | 题量/时长 | 是否计入项目总分 |
|---|---|---:|---|
| A. 研究说明与知情同意 | 家长/监护人 | 1 页，2 分钟 | 否 |
| B. 儿童基本信息与测量背景 | 家长/监护人 | 14 题，5 分钟 | 否 |
| C. 施测前状态检查 | 评估人员 | 8 题，2 分钟 | 否 |
| D. 图片情绪识别任务 | 儿童+评估人员 | 16 题，8-12 分钟 | 是，最高 20 分 |
| E. 视频情绪任务 | 儿童+评估人员 | 5 题，5-8 分钟 | 是，最高 10 分 |
| F. 家长/教师日常观察 | 家长或教师 | 12 题，5 分钟 | 否，作为外部描述 |
| G. 施测后体验与素材反馈 | 儿童/家长/评估人员 | 8-12 题，3 分钟 | 否 |

> 当前系统总分为 30 分：图片二选一 8 分、图片三选一 12 分、视频任务 10 分。图片题使用三类动画表情（开心、悲伤、恐惧）；若要加入愤怒或情境归因，必须作为新版本扩展并重新验证，不能直接套用现有阈值。

## 三、统一填写规则

- 儿童可以通过指认、触屏、手势、眼动或 AAC 作答，不要求必须说出情绪词。
- 家长和教师不得在正式题目中提示答案、重复暗示或代替儿童选择。
- 每题最多提供一次标准化重复指令；仍不作答记为“无反应”，同时记录原因。
- 采用中性鼓励：“谢谢你的回答”“我们继续看看”，不说“答对了/答错了”。
- 连续 3 题无反应、哭泣、明显回避或感官过载时暂停，暂停原因单独记录，不作为 ASD 证据。
- 主表使用单选或多选；“不适用/不知道/拒答”不能与错误答案混为一类。

## 四、A 模块：知情同意页

### 页面布局

```text
页眉：儿童表情识别调研｜研究说明
┌──────────────────────────────────────┐
│ 研究目的、流程、可能不适与退出权       │
│ 数据用途、保存时间、隐私与联系方式     │
│ □ 我已阅读并理解研究说明               │
│ □ 我同意儿童参加图片/视频任务           │
│ □ 我同意使用去标识化作答数据做研究分析   │
│ □ 我同意录屏/录像（可选，不勾选不影响参加）│
│              [同意并继续] [暂不参加]    │
└──────────────────────────────────────┘
```

### 必须呈现的说明

1. 参加完全自愿，可随时暂停或退出，不影响儿童接受的任何服务。
2. 任务可能让儿童感到无聊、困惑或对恐惧表情不舒服；儿童不适时立即停止。
3. 结果只用于本项目调研和题目改进，不作为医学诊断、入学、康复资格或能力评价依据。
4. 使用儿童编号替代姓名；单独保存联系方式与作答数据；报告只展示汇总结果。
5. 如需录像、面部数据或跨机构共享，必须单独说明用途、保存期限和撤回方式。

## 九、F 模块：家长/教师日常观察量表

### 指导语

“请根据过去 4 周儿童在家庭、幼儿园或训练环境中的通常表现作答。不是指某一天的特殊状态。若没有观察到，请选择‘不知道/不适用’。”

### 5 点量表

`0 从未｜1 很少｜2 有时｜3 经常｜4 几乎总是｜N 不知道/不适用`

| 编号 | 观察题目 | 方向 |
|---|---|---|
| F01 | 儿童能从他人的笑脸判断对方可能开心。 | 正向 |
| F02 | 儿童能从他人的哭脸或低落表情判断对方可能难过。 | 正向 |
| F03 | 儿童能注意到他人害怕或紧张的表情。 | 正向 |
| F04 | 儿童会把不同的负面情绪都说成“生气”或同一个词。 | 反向 |
| F05 | 儿童看到别人的表情后，会结合发生的事情理解原因。 | 正向 |
| F06 | 儿童在看动画人物表情时，比看真实人物更容易理解情绪。 | 描述 |
| F07 | 儿童需要成人提醒，才会注意别人的脸或情绪变化。 | 反向 |
| F08 | 儿童能用说话、指认、手势或 AAC 表达自己当下的情绪。 | 正向 |
| F09 | 儿童能在开心、悲伤、害怕之间做出区分。 | 正向 |
| F10 | 儿童在嘈杂、疲劳或陌生环境中更难理解他人情绪。 | 情境 |
| F11 | 儿童会因为恐惧、哭泣或强烈表情的图片而明显不舒服。 | 风险/耐受性 |

## 十一、数据表与分析字段

每个儿童一行基本信息，每道题一行作答记录。建议使用如下最小字段：

```text
child_id, age_months, sex, language, diagnosis_status,
task_id, task_mode, target_emotion, option_count,
selected_option, correct, score, response_mode,
response_time_ms, repeated_instruction, no_response_reason,
fatigue_level, sensory_discomfort, assessor_id, session_date
```

### 首轮调研建议输出

1. 完成率：完成题数 / 21，按年龄和诊断状态分层。
2. 正确率：图片二选一、图片三选一、视频分别统计，不只看总分。
3. 情绪混淆：开心、悲伤、恐惧各自被误选为什么。
4. 反应方式差异：语言、指认、触屏、AAC 分开报告。
5. 反应时间中位数：不要只使用平均值，记录极端值和无反应。
6. 题目可接受性：疲劳、回避、恐惧不适、需要重复指令的比例。
7. 家长/教师观察与任务表现的相关性：仅作探索性分析，不作诊断推断。

## 十二、质量控制与排除规则

- 正式分析前由至少 2 名受训人员独立检查情绪标签、正确选项和素材唯一性。
- 每道题的素材、题干、正确答案和分值必须锁定版本号，不允许事后按儿童诊断状态改答案。
- 有效作答少于 80% 时，不输出项目筛查分层，只标记“结果无效/需重测”。
- 设备故障、网络加载失败、视频未播放、儿童中止等要记录具体原因。
- 研究报告使用去标识化编号，不公开儿童面部图像、录像或原始答案截图。
- 对恐惧表情设置“暂停/跳过”流程；跳过不扣额外分，但记为缺失并在报告中说明。

## 十三、研究报告中必须使用的解释语句

> 本调研问卷用于了解儿童在特定图片、视频和情境下的表情识别表现及任务接受度，不构成医学诊断。儿童的语言能力、听视条件、注意力、疲劳、动机、设备和文化经验都可能影响结果。任何 ASD 相关判断都需要由具备资质的专业人员结合发展史、社会沟通、语言和认知评估及标准化工具综合完成。

## 十四、上线前检查清单

- [ ] 家长知情同意与儿童 assent 流程已实现。
- [ ] 儿童可以用非语言方式作答。
- [ ] 16 道图片题引用的 40 个候选文件全部存在且不重复。
- [ ] 5 个视频文件可播放，摄像头拒绝时任务仍可继续。
- [ ] 每题记录反应方式、反应时间、重复指令和无反应原因。
- [ ] F 模块不计入 30 分，且“不知道/不适用”不当作错误。
- [ ] 结果页显示分项表现、完成度和限制说明，不输出二元诊断标签。
- [ ] 数据导出已去标识化，权限、保存期限和删除流程已确定。
